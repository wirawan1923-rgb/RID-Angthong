# Hydrology Data Bot

แอปพลิเคชันสำหรับดึงข้อมูลระดับน้ำจากเว็บไซต์กรมชลประทาน

## ✨ คุณสมบัติ

- 📥 ดึงข้อมูลย้อนหลังตามจำนวนวันที่กำหนด
- 🔄 อัปเดตข้อมูลอัตโนมัติทุก 1-60 นาที
- 📊 แสดงข้อมูลแบบ Real-time ในตาราง
- 💾 บันทึกข้อมูลเป็น CSV และ JSON
- 📈 แสดงสถิติพื้นฐานของข้อมูล
- 📝 บันทึกการทำงาน (Log) แบบละเอียด

## 🚀 วิธีติดตั้งและใช้งาน
