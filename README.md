# 🌊 Hydrology Data Bot

[![Python Version](https://img.shields.io/badge/python-3.7%2B-blue.svg)](https://python.org)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

แอปพลิเคชัน Desktop สำหรับดึงข้อมูลระดับน้ำจากเว็บไซต์กรมชลประทาน (RID) โดยอัตโนมัติ

## ✨ คุณสมบัติ

- 📥 ดึงข้อมูลย้อนหลังตามจำนวนวันที่กำหนด
- 🔄 อัปเดตข้อมูลอัตโนมัติ (ปรับความถี่ได้ 1-60 นาที)
- 📊 แสดงข้อมูลแบบ Real-time ในตาราง
- 💾 บันทึกข้อมูลเป็น CSV และ JSON
- 📈 แสดงสถิติพื้นฐาน
- 📝 บันทึกการทำงาน (Log) แบบละเอียด
- 🔒 ป้องกันการถูกบล็อกด้วยการหน่วงเวลา
